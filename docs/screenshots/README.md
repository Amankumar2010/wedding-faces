# Demo screenshots

These are captures of the real macOS interface using an isolated synthetic collection. All pictured people and photographs were AI-generated for this demo, without private reference photographs. The names are fictional. No wedding-library photographs, names, paths, face embeddings, or catalogs were used in these assets.

- `demo-gallery.jpg`: browsing a named face group.
- `demo-preview.jpg`: opening a photograph in the app's preview sheet.

The tiny collection contains two generated photographs and manually reviewed groups. It illustrates the interface, not recognition accuracy or performance on a large collection. The demo title, source label and status identify it as fictional. The gallery includes the thumbnail-layout fix on the main branch.

The source photographs, generated face crops, and demo catalog remain local. Only these two reviewed screenshots are included. `PUBLIC_IMAGES.json` pins their exact SHA-256 hashes; the packager rejects any replacement until that manifest is deliberately updated after review.

You can use these screenshots when showcasing Wedding Faces. Keep the AI-generated/demo disclosure when sharing them.
