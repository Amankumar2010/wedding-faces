# Where this can go

These are directions, not shipped features or promised dates.

- **Better review:** easier corrections, clearer match evidence, less repetitive work.
- **Better evaluation:** reproducible tests for matching quality using appropriately licensed data.
- **Easier installation:** a standalone, signed and notarized macOS distribution.
- **Library management:** multiple catalogs and reconnecting relocated photo folders.
- **More formats:** expand beyond JPG and Sony ARW after testing real decoder support.

The current priority is a trustworthy local workflow. iPad support, cloud sync, and a Mac App Store release are not part of this beta.
